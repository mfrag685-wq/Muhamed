# موقع وصلها — النسخة الجديدة

موقع ثابت (Static) سريع، مبني بدون أي مكتبات خارجية. يُنتج صفحات HTML جاهزة تُرفع على Cloudflare Pages (أو أي استضافة ثابتة).

## نتائج الفحص (Lighthouse — جوال)

| الصفحة | الأداء | سهولة الوصول | أفضل الممارسات | SEO |
|---|---|---|---|---|
| الرئيسية | 98 | 100 | 100 | 100 |
| دينا تبريد | 99 | 100 | 100 | 100 |

- حجم الصفحة بعد الضغط: حوالي 10–11KB، بدون أي ملف JavaScript خارجي (الموقع القديم كان 168KB JavaScript وحده).
- خط واحد مستضاف ذاتيًا بوزنين بدل 4 خطوط من Google.
- الصور WebP بثلاثة مقاسات (480/800/1024) تُختار تلقائيًا حسب الشاشة.

## ما الذي يعالجه مقارنة بالموقع القديم

| المشكلة في الموقع القديم | الحل في النسخة الجديدة |
|---|---|
| رابط admin ظاهر للزوار | لا توجد لوحة تحكم، والرابط القديم يحوّل للرئيسية (301) |
| صفحات المدن نسخ مكررة | فقرة مكتوبة لكل خدمة في كل مدينة، ومناطق ومسارات وأسئلة خاصة بالمدينة |
| محتوى قليل (150 كلمة) | صفحات خدمات كاملة: جداول، فئات العملاء، عوامل السعر، أسئلة شائعة |
| لا بيانات قانونية | خانات للسجل التجاري والرقم الضريبي والعنوان تظهر في الفوتر وفي الـ Schema، وصفحتا خصوصية وشروط |
| JavaScript ثقيل و4 خطوط | لا JavaScript خارجي، وخط واحد مستضاف ذاتيًا |
| صور JPG كبيرة | WebP متجاوب، وأولوية تحميل لصورة الـ Hero |
| ترويسات أمان ناقصة | CSP و X-Frame-Options و Permissions-Policy و HSTS في ملف `_headers` |
| Schema ناقص | MovingCompany و Service و FAQPage و BreadcrumbList و BlogPosting في كل صفحة مناسبة |
| لا أيقونات للجوال | favicon و apple-touch-icon و manifest |
| لا نموذج طلب | نموذج طلب عرض سعر يحوّل الطلب إلى رسالة واتساب جاهزة |
| لا تتبع للتحويلات | تتبع ضغطات الاتصال وواتساب وإرسال النموذج تلقائيًا عند تفعيل GA4 |

## الصفحات (35 صفحة)

- الرئيسية، صفحة جميع الخدمات، صفحة الشركات، طلب عرض سعر
- 7 صفحات خدمات (بنفس روابط الموقع القديم للحفاظ على ترتيب جوجل)
- 15 صفحة مدينة: دينا تبريد ونقل عفش ولوري × الرياض وجدة والدمام ومكة والمدينة
- المدونة + 3 مقالات
- من نحن، تواصل معنا، سياسة الخصوصية، الشروط والأحكام، صفحة 404

## هيكل الملفات

```
wslha-site/
├── build.mjs              ← سكربت البناء (يولّد كل الصفحات)
├── src/
│   ├── data/
│   │   ├── site.mjs       ← ★ بيانات الشركة (الهاتف، السجل التجاري، العنوان، GA4...)
│   │   ├── services.mjs   ← محتوى صفحات الخدمات
│   │   ├── cities.mjs     ← المدن ومحتوى كل خدمة في كل مدينة
│   │   └── posts.mjs      ← مقالات المدونة
│   ├── styles.css         ← التصميم (يُدمج داخل الصفحات تلقائيًا)
│   ├── main.js            ← القائمة، نموذج الطلب، تتبع التحويلات
│   └── assets/            ← الخطوط والصور والأيقونات
└── dist/                  ← الناتج النهائي (لا يُرفع على git، يُولّد بالبناء)
```

## التشغيل والبناء

يحتاج Node.js 18 أو أحدث فقط، ولا يحتاج `npm install`.

```bash
cd wslha-site
node build.mjs        # ينتج مجلد dist/
```

## النشر على Cloudflare Pages

1. ضع مجلد `wslha-site` في مستودع Git مستقل (أو اختر هذا المجلد كجذر المشروع).
2. في Cloudflare: **Workers & Pages ← Create ← Pages ← Connect to Git**.
3. الإعدادات:
   - Build command: `node build.mjs`
   - Build output directory: `dist`
   - Root directory: `wslha-site` (إذا بقي داخل هذا المستودع)
4. اربط الدومين `wslha.store` (أو الدومين الجديد) بالمشروع.
5. **تحويل www:** من **Rules ← Redirect Rules** أنشئ قاعدة تحويل دائم 301 من `www.wslha.store/*` إلى `https://wslha.store/${1}`. (ملف `_redirects` لا يدعم التحويل بين النطاقات.)
6. **إحصائيات بدون كوكيز (اختياري):** فعّل Cloudflare Web Analytics من لوحة المشروع، وسياسة الأمان تسمح بها مسبقًا.

> ⚠️ لا تدمج هذا المجلد في الفرع الرئيسي لهذا المستودع كما هو: ملف `wrangler.jsonc` في الجذر ينشر كل الملفات من `./`، فسيُنشر الموقع داخل مشروع آخر. الأفضل نقله لمستودع خاص به.

## قبل الإطلاق (مهم)

1. **املأ `src/data/site.mjs`:** الاسم في السجل التجاري، رقم السجل، الرقم الضريبي، العنوان، البريد، أوقات العمل الفعلية، روابط التواصل الاجتماعي. أي حقل فارغ لا يظهر في الموقع.
2. **الصور:** استبدل صور `src/assets/img/` بصور حقيقية من أسطولكم بنفس الأسماء. لتحويل صورة جديدة:
   ```bash
   for w in 480 800 1024; do convert photo.jpg -resize ${w}x -quality 72 truck-refrigerated-$w.webp; done
   convert photo.jpg -resize 1200x630^ -gravity center -extent 1200x630 -quality 78 truck-refrigerated-og.jpg
   ```
3. **راجع الأرقام في المحتوى:** الحمولات التقريبية في جدول اللوري، وأوقات العمل، وما يشمله نقل العفش، وطابقها مع الواقع.
4. **الإحصائيات في الرئيسية:** حقلا `stats.years` و `stats.trips` لا يظهران إلا إذا مُلئا بأرقام حقيقية.
5. **Google Search Console:** ضع رمز التحقق في `googleVerification`، ثم ارفع `https://wslha.store/sitemap.xml`.
6. **Google Analytics 4 (اختياري):** ضع المعرف في `ga4`، وسياسة الأمان (CSP) تتحدث تلقائيًا عند البناء. أحداث التحويل: `click_call` و `click_whatsapp` و `generate_lead`.

## إضافة محتوى

- **مقال جديد:** انسخ عنصرًا في `src/data/posts.mjs` وغيّر الحقول، ثم أعد البناء. يُضاف تلقائيًا إلى المدونة و sitemap.
- **مدينة جديدة:** أضفها في `cities` داخل `src/data/cities.mjs`، واكتب لها فقرة لكل خدمة في `cityServiceText`. لا تنسخ فقرة مدينة أخرى، فالمحتوى المكرر يضر الترتيب.
- **تعديل نص خدمة:** من `src/data/services.mjs`.

## ملاحظات تقنية

- الروابط بدون شرطة في النهاية (`/services/refrigerated-truck-rental`)، مطابقة للموقع القديم. Cloudflare Pages يخدم `x.html` على `/x` تلقائيًا.
- CSS مدمج في كل صفحة (حوالي 14KB قبل الضغط)، فلا يوجد ملف يعطّل عرض الصفحة.
- سياسة CSP تسمح بالسكربت الداخلي عبر بصمة SHA-256 تُحسب عند كل بناء، فلا تعدّل `_headers` في `dist` يدويًا.
- نموذج طلب السعر لا يحفظ أي بيانات على الخادم؛ ينشئ رسالة واتساب فقط.
