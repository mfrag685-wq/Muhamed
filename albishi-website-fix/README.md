# نسخة معدّلة من موقع البيشي: دليل التقني

هذا المجلد نسخة معدّلة من الصفحة الحالية في https://www.albishi.com.sa/ (كما كانت يوم 26 أكتوبر 2026).
فيه إصلاح المشاكل التي ظهرت في الفحص، وإعادة ترتيب الصفحة لتبدأ بالخضار والفواكه
لأنها حوالي 70% من نشاط الشركة، والمعدات الزراعية قسم ثانوي.

## محتويات المجلد

| الملف | الغرض |
|---|---|
| `index.html` | الصفحة المعدّلة (تحل محل index.html الحالي) |
| `assets/site.css` | ملف Tailwind مبني مسبقاً (22KB)، بدل `cdn.tailwindcss.com` |
| `.htaccess` | تحويل https، ضغط، تخزين مؤقت، ترويسات أمان (Apache) |
| `robots.txt` و `sitemap.xml` | لمحركات البحث (كانت ترجع 404) |
| `scripts/optimize-media.bat` | ضغط الصور والفيديوهات على ويندوز |
| `scripts/optimize-media.sh` | نفس السكربت لـ Linux/Mac |
| `tailwind.config.js` و `tailwind.input.css` | لإعادة بناء site.css عند تعديل الكلاسات |

## خطوات التركيب (بالترتيب)

> **مهم:** شغّل سكربت الضغط (الخطوة 2) قبل رفع index.html الجديد. الصفحة تحاول تحميل الصور
> المضغوطة أولاً، وإذا لم تجدها ترجع للأصلية. أما فيديو المعرض فلا يوجد له بديل:
> يظهر صندوق الفيديو فارغاً إلى أن تُنشأ النسخة المضغوطة.

### 1. خذ نسخة احتياطية
انسخ مجلد الموقع الحالي كاملاً قبل أي تعديل.

### 2. اضغط الصور والفيديوهات
1. ثبّت ffmpeg (نسخة "full" من https://www.gyan.dev/ffmpeg/builds/) وأضفه إلى PATH.
2. من داخل مجلد الموقع (الذي فيه `images` و `videos`):
   ```
   scripts\optimize-media.bat
   ```
3. السكربت **لا يحذف ولا يعدّل** أي ملف أصلي. يكتب فقط في:
   - `images/web/thumb/*.webp`: مصغرات المعرض (حوالي 50KB بدل 23MB)
   - `images/web/large/*.webp`: صور العرض المكبّر (حوالي 250KB)
   - `images/web/logo-256.png` و `favicon-32.png` و `apple-touch-icon.png`: الشعار (الأصلي 1.4MB)
   - `images/web/og-cover.jpg`: صورة المشاركة في واتساب وتويتر
   - `images/web/hero-poster.jpg` و `equipment-poster.jpg`: صور غلاف الفيديوهات
   - `videos/web/hero.mp4`: أول 20 ثانية من فيديو المعرض (الأصلي 463MB)
   - `videos/web/equipment.mp4`: فيديو المعدات (الأصلي 1.8GB)

تمت تجربة السكربت على صورة حقيقية من الموقع: `DSC06343.JPG` (23MB) صارت 48KB مصغرة و224KB مكبّرة.

**الكتالوج PDF (48MB):** نسخة Linux من السكربت تضغطه تلقائياً إذا كان ghostscript مثبتاً.
على ويندوز استخدم أي أداة ضغط PDF (مثل "Reduce File Size" في Acrobat)، والهدف أقل من 8MB.

### 3. ارفع الملفات
ارفع `index.html` و `assets/` و `.htaccess` و `robots.txt` و `sitemap.xml` إلى جذر الموقع.
**لا ترفع** مجلد `scripts` ولا `README.md` ولا ملفات tailwind.

### 4. صورة الواجهة (من الشركة)
الواجهة الآن صورة خضار وفواكه بدل فيديو المعدات. ضع صورة **حقيقية** من مستودعات الشركة
أو التبريد أو الشاحنات بالاسم:
```
images/web/hero-produce.webp   (عرض 1600px تقريباً)
```
وإلى أن توجد تظهر صورة احتياطية من Unsplash.

### 5. إعدادات السيرفر (httpd.conf)
- فعّل `mod_rewrite` و `mod_headers` و `mod_deflate` و `mod_expires`، وتأكد أن `AllowOverride All` للمجلد.
- أضف `ServerTokens Prod`، لأن السيرفر يعلن حالياً `Apache/2.4.58 (Win64) PHP/8.2.12`.
- **احذف أو اقفل phpMyAdmin** (`/phpmyadmin/` موجود ويرد 403) ولوحات XAMPP.
- الأفضل على المدى القريب: انقل الموقع من XAMPP إلى استضافة حقيقية، مثل
  Cloudflare Pages أو Netlify (مجانية للمواقع الثابتة)، والفيديوهات إلى يوتيوب.
  السيرفر الحالي أعطى خطأ 502 أكثر من مرة أثناء الفحص.

### 6. بعد الرفع
- سجّل الموقع في Google Search Console وأرسل `sitemap.xml`.
- أنشئ أو حدّث Google Business Profile للشركة في جدة.
- افحص الصفحة في https://pagespeed.web.dev. المتوقع أكثر من 85 على الجوال بعد ضغط الوسائط.

## بيانات تحتاجها من الشركة

كلها في كائن واحد أعلى السكربت في `index.html` اسمه `SITE_CONFIG`.
**أي قسم يبقى فارغاً لا يظهر في الموقع**، فلا تُعرض أي معلومة غير مؤكدة.

```js
const SITE_CONFIG = {
    foundedYear: 1989,              // سنوات الخبرة تُحسب تلقائياً (37 في 2026)
    whatsapp: '966535667701',       // رقم استقبال طلبات عرض السعر

    social: { x: '', linkedin: '', instagram: '', facebook: '', youtube: '' },

    origins: [                      // دول الاستيراد الفعلية
        // { flag: '🇪🇬', ar: 'مصر', en: 'Egypt' },
    ],
    certifications: [               // الشهادات والتراخيص الفعلية فقط
        // { ar: 'ترخيص الهيئة العامة للغذاء والدواء', en: 'SFDA Licensed' },
    ],
    seasons: [                      // مواسم الذروة: أرقام الأشهر 1 إلى 12
        // { ar: 'برتقال', en: 'Oranges', months: [12, 1, 2, 3, 4] },
    ]
};
```

باقي ما يُطلب من الشركة:
- صور حقيقية: المستودعات، التبريد، الشاحنات، الفريق، والمنتجات نفسها (لتحل محل صور Unsplash في بطاقات المنتجات).
- روابط حسابات التواصل الاجتماعي.
- رقم السجل التجاري والرقم الضريبي (يُفضّل إضافتهما في التذييل).

### أفكار جديدة (الخضار والفواكه أولاً)
مأخوذة من مواقع موزعي المنتجات الطازجة، مثل Harvest Trading في جدة والرياض والمدينة، وWaha Fruits،
وRobinson Fresh. هذه المواقع تبرز القطاعات التي تخدمها، وسلسلة التبريد، والتوفر على مدار العام، ودول المنشأ.

1. **واجهة جديدة**: "خضار وفواكه طازجة من المزرعة إلى منشأتك يومياً" مع زرين: "اطلب عرض سعر" و"واتساب".
   المعدات صارت رابطاً ثانوياً تحت الأزرار.
2. **شريط أرقام**: سنوات الخبرة، عام التأسيس، جدة والرياض، سوق الخضار المركزي.
   كلها معلومات منشورة أصلاً في الموقع، ولم يُضف أي رقم غير مؤكد.
3. **قسم "قطاعات نخدمها"**: الهايبر ماركت، المطاعم والمقاهي، الفنادق والتموين، تجار الجملة.
4. **قسم "كيف نعمل"**: الاستيراد ثم الفحص والفرز ثم التخزين المبرّد ثم التوزيع.
5. **دول المنشأ والشهادات وتقويم المواسم**: أقسام جاهزة تظهر عند تعبئة بياناتها.
   أسماء الأشهر تُترجم تلقائياً حسب اللغة.
6. **نموذج "طلب عرض سعر" للشركات**: الاسم، المنشأة، القطاع، المدينة، المنتجات، الكمية، الجوال.
   يُرسل كرسالة منسّقة إلى واتساب الشركة، فلا يحتاج خادماً ولا قاعدة بيانات.
7. **شريط ثابت أسفل شاشة الجوال** (اتصال، واتساب، عرض سعر)، وزر واتساب عائم على الكمبيوتر.
8. **القائمة** صارت: المنتجات، المعدات، قطاعاتنا، عملاؤنا، المعرض، الكتالوج، تواصل معنا، وزر "طلب عرض سعر" مميز.
   "رؤيتنا ورسالتنا" ما زالت في الصفحة وفي قائمة الجوال.
9. عنوان الصفحة ووصفها لمحركات البحث يبدآن بالخضار والفواكه.

### اقتراحات للمرحلة التالية
- صفحة مستقلة لكل لغة (`/en/` و `/ur/`...) مع `hreflang`. حالياً الترجمة بالجافاسكربت، وقوقل يرى العربية فقط.
- صفحة منتجات مفصلة: صورة حقيقية لكل صنف، بلد المنشأ، الموسم، طريقة التعبئة (كرتون، كيس، وزن).
- قسم "أسعار اليوم" أو "المتوفر هذا الأسبوع" يحدّثه الموظف، وهو مفيد جداً لعملاء الجملة.
- رقم السجل التجاري والرقم الضريبي وشعار ترخيص هيئة الغذاء والدواء في التذييل.
- قسم "انضم كمورّد" للمزارع والمصدّرين.
- ربط نموذج عرض السعر بقاعدة بيانات أو CRM عند نمو الطلبات.

## إعادة بناء CSS (عند تعديل الكلاسات فقط)
```
npx tailwindcss@3.4.17 -c tailwind.config.js -i tailwind.input.css -o assets/site.css --minify
```

## ما تم اختباره
- الصفحة في Chromium بمقاس كمبيوتر (1366px) وجوال (390px): لا أخطاء جافاسكربت ولا تمرير أفقي.
- قائمة الجوال، وتبديل اللغات الست مع الاتجاه، ونموذج عرض السعر (التحقق من الحقول ورسالة واتساب)،
  ونافذة المعرض (Esc والصور المكبّرة)، وظهور أقسام `SITE_CONFIG` عند تعبئتها.
- سكربت الضغط `.sh` على صورة حقيقية من الموقع وعلى فيديو تجريبي.
  **نسخة `.bat` لم تُختبر على ويندوز**. فيها نفس أوامر ffmpeg، فإذا ظهر خطأ جرّب أمراً واحداً يدوياً.
